# Лабораторная работа

## Вариант 9

### Условие задачи

Составить программу, которая в зависимости от даты, введенной одним числом `ddmm`, где `dd` — число, `mm` — месяц, выводит на экран соответствующий знак Зодиака.

## Алгоритм

1. Ввести дату одним числом в формате `ddmm`.
2. Выделить день:
   
   `day = date / 100`

3. Выделить месяц:
   
   `month = date % 100`

4. С помощью условных операторов определить диапазон дат.
5. Вывести соответствующий знак Зодиака.

## Код программы

```c
#include <stdio.h>

int main()
{
    int date, day, month;
    printf("Введите дату в формате ddmm: ");
    scanf("%d", &date);
    day = date / 100;
    month = date % 100;
    switch (month)
    {
        case 1:
            printf("Знак Зодиака: %s\n", day < 20 ? "Козерог" : "Водолей");
            break;
        case 2:
            printf("Знак Зодиака: %s\n", day < 19 ? "Водолей" : "Рыбы");
            break;
        case 3:
            printf("Знак Зодиака: %s\n", day < 21 ? "Рыбы" : "Овен");
            break;
        case 4:
            printf("Знак Зодиака: %s\n", day < 20 ? "Овен" : "Телец");
            break;
        case 5:
            printf("Знак Зодиака: %s\n", day < 21 ? "Телец" : "Близнецы");
            break;
        case 6:
            printf("Знак Зодиака: %s\n", day < 21 ? "Близнецы" : "Рак");
            break;
        case 7:
            printf("Знак Зодиака: %s\n", day < 23 ? "Рак" : "Лев");
            break;
        case 8:
            printf("Знак Зодиака: %s\n", day < 23 ? "Лев" : "Дева");
            break;
        case 9:
            printf("Знак Зодиака: %s\n", day < 23 ? "Дева" : "Весы");
            break;
        case 10:
            printf("Знак Зодиака: %s\n", day < 23 ? "Весы" : "Скорпион");
            break;
        case 11:
            printf("Знак Зодиака: %s\n", day < 22 ? "Скорпион" : "Стрелец");
            break;
        case 12:
            printf("Знак Зодиака: %s\n", day < 22 ? "Стрелец" : "Козерог");
            break;
        default:
            printf("Некорректный месяц\n");
    }
    return 0;
}
```
